# CLI application icon

The CLI uses the white monolith with an **orange** accent from version 1.84.0. Desktop uses cyan and Android green. `logo.png` is the CLI source artwork; `logo-256.png` and `logo-32.png` are resized previews. `app.ico` contains orange PNG frames at 16, 20, 24, 32, 40, 48, 64, 128 and 256 pixels. The terminal character rendering retains its theme foreground with a fixed orange accent.

Re-export this variant from the repository root with `./build/update-branding-assets.ps1 -Target CLI` on Windows. See [branding](../../../docs/branding.md) for all variants and custom desktop logo settings.
