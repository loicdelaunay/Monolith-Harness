# Material Icon Theme

Icons from https://github.com/material-extensions/vscode-material-icon-theme

Source commit: `b6bfe581ef3099f8574c3f88b7244c651ca0e369`. MIT license reproduced in LICENSE.

The native chat embeds a COLR/CPAL font generated from these SVGs with `build/generate-material-file-font.py` (fonttools 4.60.1). No icon download is required at runtime.
