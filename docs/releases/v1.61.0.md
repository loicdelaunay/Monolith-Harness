# Monolith Harness 1.61.0

This release adds quick, reusable model and thinking presets to both GUI and CLI settings while keeping each interface at the same version.

## Quick model levels

- Configure up to 10 ordered levels. Each combines a provider and model, thinking effort, and Chat or Agent mode; names are optional, and levels can be reordered.
- The feature is off by default. When enabled, **Simple** presents the levels on a stepped slider, while **Advanced** keeps the model search and individual controls.
- In Advanced mode the model and thinking selectors sit side by side when the window has enough room. Narrow windows retain the combined selector.
- Unavailable models are identified so a preset can be updated in Settings → Shortcuts. Applying a level updates its provider, model, thinking preference and conversation mode together.

## Downloads

GUI and CLI packages are published separately for Windows x64 and Fedora Linux x64. macOS packages remain paused. Archives contain only the application, license and startup instructions; existing portable data stays in place when updating.

Verify downloads with the attached **SHA256SUMS.txt** on each release.
