# Monolith Harness 1.77.0

GUI and CLI share version 1.77.0. This release includes the changes since 1.75.1.

## Highlights

- Adds the **Information** skill, enabled in **Settings → Skills → Information** and available as `/informations`. Select date/time, the computer timezone or UTC, OS and shell, language and regional formats, CPU/runtime memory, application/.NET/bundled Python versions, development tools, selected environment variables, paths, computer identity, conversation context and personal notes. A local preview shows the selected information before sharing it with the conversation model.
- With automatic context enabled, selected information is refreshed for each user turn in Agent and Chat modes. Compatible direct models and their subagents can request fresh selected sections with `get_information`. OpenCode and ACP agents receive automatic snapshots without claiming the application tool exists in their native host. Paths, computer identity, hardware, tool detection and environment variables are off by default. Development-tool detection checks file presence without running commands or claiming installed versions; runtime memory is explicitly distinguished from physical RAM.
- Adds **Settings → About → Automatic update checks**: Never, every hour (default), every day or every week. Checks run at startup and at the selected interval while the app is open. Manual checking remains available when automatic checks are disabled.
- Allows **manual update installation with unsent drafts**, saving their text and image attachments locally and restoring them after restart. Running agents must finish before installation; automatic installation still waits for drafts and editing windows to finish.
- Adjusts slash-skill completion to add a space for continued typing. Enter/Tab completion is deferred until the native key dispatch finishes, preventing an extra newline or immediate message submission.

See [CHANGELOG.md](https://github.com/loicdelaunay/Monolith-Harness/blob/v1.77.0/CHANGELOG.md) for details.

## Downloads

Choose the GUI or CLI archive for Windows x64 or Fedora Linux x64. Historical Windows archive-name aliases contain the same executable. `SHA256SUMS.txt` lists the fingerprints of all downloads.

Archives contain only the executable, license and startup instructions. They contain no database, credentials, logs or user workspace.

## Updating

Close the application, back up your workspace, and replace only the executable. Keep `database.sqlite`, `workspace/` and your existing resources. Optional Git, Docker/Podman, OpenCode and MCP integrations keep their own prerequisites. Manual installation with draft recovery is available when updating from a build that supports it.

## Build and publication

GUI and CLI compile and are published locally on Windows x64 at 1.77.0. No new automated functional tests were run for these changes. GitHub rebuilds both interfaces for Windows x64 and Fedora Linux x64, checks clean archive contents and uploaded file fingerprints, and prepares both releases as drafts before publication.
