# OhMyHarness CLI 1.27.0

Choose `OhMyHarness-CLI-v1.27.0-win-x64.zip`, `OhMyHarness-CLI-v1.27.0-osx-arm64.tar.gz` (Apple Silicon), `OhMyHarness-CLI-v1.27.0-osx-x64.tar.gz` (Intel), or `OhMyHarness-CLI-v1.27.0-linux-x64.tar.gz` (Fedora 44). Extract into a writable folder and run `omh` (`omh.exe` on Windows). Enter `/connect` to configure a model provider. Check the selected archive against the attached `SHA256SUMS.txt`.

The optional **GIT** skill offers approved Git inspection, commits and synchronization. **FILE INDEX** creates and maintains `index.ohm` for searching files and folders by path or description. These tools share the same 1.27.0 engine and skill settings as the [GUI release](https://github.com/loicdelaunay/OhMyHarness/releases/tag/v1.27.0). See the [GIT and FILE INDEX guide](../git-file-index.md) and [full changelog](../../CHANGELOG.md).

The archive contains only the executable, MIT license and startup instructions. It has no database, profiles, credentials, logs or user data. macOS builds are unsigned and not notarized. On Mac or Linux, close the app and replace only the executable when updating.
