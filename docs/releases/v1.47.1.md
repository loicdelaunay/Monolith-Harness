# Monolith Harness 1.47.1

## Provider navigation

The **Model and thinking** popup now has a settings icon immediately before the model-refresh button. It opens **Settings → Providers** directly. If settings are already open, the same window is brought forward and unsaved fields are kept. Requests made while settings are loading also reach Providers once loading finishes.

The **Providers** title, **Add provider** menu and editor **Back** button remain visible while the provider list or a long form scrolls. Opening a provider, adding a preset or returning to the list resets the content to the top. Editing fields keeps the current scroll position, and Back retains the provider draft until it is saved or cancelled.

## Downloads and updating

Both **GUI and CLI 1.47.1** have **Windows x64** and **Linux x64** archives. The CLI retains its existing behavior; its version and shared engine are aligned with the GUI. macOS publication remains paused.

Each archive contains only its standalone launcher, **LICENSE** and **README.txt**. Windows legacy-name archives are identical compatibility aliases; each release includes **SHA256SUMS.txt**.

Extract GUI and CLI into separate writable folders. To update manually, close the application and replace only **MonolithHarness.exe** on Windows or **MonolithHarness** on Linux. Keep **database.sqlite** and existing resources.
