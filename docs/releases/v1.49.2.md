# Monolith Harness 1.49.2

## Smart web research

**Smart** is the recommended default for HTTP web research. Downloaded pages are saved in the conversation's tool-artifact cache, with a short preview and outline returned to the model. The model can use **web_http_search** and **web_http_read** to find and read relevant passages, reuse saved results, and limit context consumption. Readable HTML text preserves headings and links without executing JavaScript; raw content remains available.

**Legacy** returns body and headers directly in the conversation. Choose the mode in GUI **Settings → Skills → Web research**, or CLI settings. Historical Partial/Full preferences and tool calls remain compatible. Downloads are capped at 1 MiB, with explicit truncation when that limit is reached; normal permissions and Plan restrictions remain enforced.

## Conversation maintenance and context

- **Clean tool artifacts** is enabled by default after **seven days without use**. Reading or searching a saved result renews its retention. Maintenance runs at startup and hourly, preserves active conversations, and deletes only known HTTP cache files. Project sources, conversation documents and release binaries remain outside this cleanup.
- The standard context fallback is now **256,000 tokens**. Provider-reported model capacities and explicit per-model overrides take priority. Existing automatic profiles pick up the new fallback; saved custom limits, local-model defaults and other model-specific estimates retain their values.

## GUI fixes

- Provider title, Add provider and Back controls share a fixed responsive header. Back reliably returns to the provider list while retaining unsaved drafts; editing a provider name no longer reopens the form.
- Model retries have a **four-second display grace period**, showing **Model thinking** before a persistent retry notice. Retry counts, request timing and final errors retain their existing behavior.

Both **GUI and CLI 1.49.2** are available for **Windows x64** and **Linux x64**. Each archive contains the standalone launcher, **LICENSE** and **README.txt**. Both releases include **SHA256SUMS.txt** and Windows compatibility aliases. macOS publication remains paused.

To update manually, close all application instances and replace only **MonolithHarness.exe** on Windows or **MonolithHarness** on Linux. Keep **database.sqlite**, **workspace/** and existing resources. Extract GUI and CLI into separate writable folders.
