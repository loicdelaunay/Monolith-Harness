# Monolith Harness 2.5.0

This release includes the changes prepared for 2.4.0 and 2.5.0.

## Chat and tools

- Readable `edit_source` parameters with a Raw / Formatted switch, numbered lines and grouped changes: red removals, green additions and orange before/after replacements. The original JSON remains available.
- `/mcp` commands to inspect and configure servers and control their availability per conversation. Direct model providers can use authorized MCP servers in Chat mode, subject to resource and permission settings.
- Reasoning resumes in chronological segments after interactive questions, including restored conversations and branches.
- Resume a user message in the editor with its attachments while preserving a backup of the previous history.
- Tool activity uses one circular indicator that continues when the window loses focus and pauses when minimized.

## Desktop

- More resilient title bar initialization, system control fallback and a draggable top edge.
- Project instructions available from the project context menu.
- Provider removal also removes associated shortcuts; settings validation errors appear beside Save.
- Selectable proofreader reasoning effort, disabled by default to reduce waiting.
- Debug Storage tab with on-demand background totals by category.

## Downloads

GUI, CLI and Server are available for Windows x64 and Linux x64. Flutter Android is a signed ARM64 APK. SHA256SUMS.txt is included in every release.

## Validation and limits

- Local desktop and native Windows builds and GUI/CLI/Server publication completed successfully.
- The targeted interactive reasoning chronology scenario passed 17 checks in an isolated desktop instance.
- MCP availability still depends on the configured provider and server permissions; native external agents do not use the host MCP bridge.
- The existing compatibility check for upgrading an existing database failed on the previous releases as well; it remains a known issue separate from the package build.
