# Monolith Harness 1.57.1

## What changed

- Corrects the Windows WinUI statistics card and updates HTTP regression checks for the current Smart/Legacy modes. Includes all features from 1.57.0 below.
- Adds **Antigravity ACP** and **ChatGPT Plus / Pro through Codex** to provider settings, onboarding and the CLI connection wizard. Codex uses account sign-in and the plan's Codex allowance.
- Streams ACP responses, reasoning and tool activity with model discovery, supported thinking levels, cancellation and local history replay. Codex Chat and Plan use read-only mode; Antigravity currently requires Agent / Execute and manages its native permissions.
- Improves Markdown spacing and adds embedded offline **KaTeX / LaTeX** and **Mermaid** rendering in chat and file previews.
- Groups intermediate replies, reasoning and tools into one expandable activity bubble while keeping the final answer visible.
- Adds persistent up/down controls for queued messages and routes asset captures through the configured image observer.
- Includes configurable Chat reasoning, disabled by default and saved independently from Agent.

## Downloads and requirements

GUI and CLI packages are available for **Windows x64** and **Fedora Linux x64**. macOS publication remains suspended.

ACP connections need **Node.js with npm** and the corresponding authenticated agent. Native agent tools replace Monolith's internal tool and subagent orchestration for these providers. ACP opens a new session per turn and replays local history; native persistent session resumption is not yet supported. See [ACP connection instructions](https://github.com/loicdelaunay/Monolith-Harness/blob/main/docs/acp-connections.md).

Archives contain only the launcher, license and startup instructions. Each release includes SHA256SUMS.txt and Windows compatibility filenames for older updaters.
