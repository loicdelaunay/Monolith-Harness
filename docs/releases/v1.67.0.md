# Monolith Harness 1.67.0

This release expands command validation settings and restores an explicit Allow all permission mode. GUI and CLI use the same settings and command approval engine.

## Validation setup in Settings / Permissions

- LANCET setup now lives in the dedicated Command validation section. Selecting Automatic no longer starts an installation dialog.
- Download and prepare the pinned LANCET Nano model explicitly, or import a complete verified 0.4.3 bundle. Manual import preserves its source folder and checks the expected files and hashes.
- A bundle-local wheels directory can provide compatible Python CPU dependencies for offline installation. Otherwise the pinned CPU components are downloaded from PyPI.
- An unprepared or unavailable validator falls back to human approval.

## Use an existing model

Choose any configured local or API chat model as the command validator instead of LANCET. Local models must already be prepared. The settings explain when an API provider receives commands, shell and working directory, and that these requests may be billed.

The validator receives no execution tools. Its response must be structured, bounded and tied to the exact command. Risky, uncertain, invalid or unavailable analysis requires one-time human approval. External engines unable to enforce analysis without tools also fall back to human approval. Model analysis can make mistakes and does not replace a security sandbox.

## Allow all

**Allow all** is again available beside Ask, Automatic and Deny all. The GUI marks it with an orange warning icon. It accepts permission requests without model validation; explicit project Ask and Deny rules still apply. Automatic remains a separate mode using the selected validator. Ask remains the default.

## Downloads

Separate GUI and CLI packages are provided for Windows x64 and Fedora Linux x64. Archives contain only the application, license and startup instructions; they do not contain user data or the optional LANCET model. Preserve existing portable data when replacing the executable.

Each release includes **SHA256SUMS.txt** and Windows compatibility archive names for older update clients.
