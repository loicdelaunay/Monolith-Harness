# Monolith Harness 1.51.0

## Subagent task progress

Subagents announce and maintain their own structured task plans through **todowrite**. GUI conversation cards, sidebar rows, detailed agent views and CLI progress bars now show **completed tasks / declared tasks**, the current task and any cancelled tasks. The model-request budget remains unchanged and is no longer displayed as task progress.

- Each agent's plan is isolated from the parent conversation, saved in its transcript and retained through context compaction.
- Progress remains indeterminate until a plan is provided. Unfinished work is never automatically marked completed when an agent stops.
- OpenCode's native task polling updates the matching agent plan when native tools are enabled.
- **Parent conversation** is now an accent button in a fixed header above the GUI subagent scroll area, with translated labels and statuses. It remains visible during scrolling and progress updates.

Task-plan updates use model/tool requests and may consume additional tokens. Older agent transcripts without a declared plan cannot provide a task completion percentage.

## Dashboard: Consumption and Speed

The GUI **Consumption** tool is now **Dashboard**, with two native tabs:

- **Consumption** retains token totals, usage charts, model distribution, call details and CSV export.
- **Speed** adds average recorded throughput, slowest/fastest calls, a timeline, model comparisons, measured-call details and CSV export.

Both tabs share **Today / 3 days / 7 days / 30 days / 1 year**, provider, model, activity and project filters, with automatic refresh every 15 seconds. Speed uses existing output-token counts and request durations; durations include waiting and reasoning. Estimated token counts are labelled, while failed/interrupted calls and records without valid measurements are excluded explicitly. No additional model requests or database fields are required.

## Downloads and updating

Both **GUI and CLI 1.51.0** are available for **Windows x64** and **Linux x64**. Each archive contains the standalone launcher, **LICENSE** and **README.txt**. Both releases include **SHA256SUMS.txt** and Windows compatibility aliases. macOS publication remains paused.

To update manually, close all application instances and replace only **MonolithHarness.exe** on Windows or **MonolithHarness** on Linux. Keep **database.sqlite**, **workspace/** and existing resources. Extract GUI and CLI into separate writable folders.
