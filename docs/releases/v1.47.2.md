# Monolith Harness 1.47.2

The GUI thinking status chip now shows only **Le modèle réfléchit** while the model reasons. It no longer repeats reasoning excerpts or an idle counter in the chip. The full streamed reasoning remains available in its own panel. Response, context-loading and tool status indicators keep their existing behavior.

Both **GUI and CLI 1.47.2** are available for **Windows x64** and **Linux x64**. The CLI retains its existing behavior; its version is aligned with the GUI. Each archive contains the standalone launcher, **LICENSE** and **README.txt**. Both releases include **SHA256SUMS.txt** and Windows compatibility aliases.

To update manually, close the application and replace only **MonolithHarness.exe** on Windows or **MonolithHarness** on Linux. Keep **database.sqlite** and existing resources. Extract GUI and CLI into separate writable folders.
