# Monolith Harness 1.64.0

This release brings the composer and conversation improvements from versions 1.62 through 1.64 to the portable GUI, with matching CLI packages.

## Composer and conversations

- Replaces the More information panel with a compact model and thinking button beside Stop and Send. Clicking the model opens the Simple/Advanced selector.
- Adds independent, enabled-by-default settings for token speed and context usage. Moving between their indicators immediately switches the detail popup.
- Keeps the final answer bubble hidden during preparation, reasoning and tool calls until actual answer text arrives. Reasoning and tools remain visible in their activity group.
- Sizes user bubbles to their content and aligns them to the right.
- Displays square resource and attachment previews with image viewing, zoom and removal on hover. Removing a reference preserves the original file.
- Provides quick AI level selection beside Stop and Send when several shortcut levels are configured.
- Shows update progress directly beneath the sidebar update button.
- Reads the displayed application version from the installed executable so the version badge and update checks stay aligned.

## Downloads

GUI and CLI packages are published separately for Windows x64 and Fedora Linux x64. Archives contain only the application, license and startup instructions. Existing portable data stays in place when updating.

Each release includes compatibility download names and **SHA256SUMS.txt** for verification.
