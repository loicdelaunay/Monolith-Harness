# Monolith Harness 1.47.3

The GUI generation-speed panel now follows the style of the context panel. A prominent average speed and status badge sit above rounded cards showing the minimum, average and maximum for the current or last response and the discussion. The panel updates live, adapts to narrow windows and text zoom, and scrolls on shorter screens.

Throughput calculations remain unchanged. Live estimates are labelled, and unavailable minimums and maximums show a dash; last-response extrema are still kept only for the current application session.

Both **GUI and CLI 1.47.3** are available for **Windows x64** and **Linux x64**. The CLI retains its existing behavior; its version is aligned with the GUI. Each archive contains the standalone launcher, **LICENSE** and **README.txt**. Both releases include **SHA256SUMS.txt** and Windows compatibility aliases.

To update manually, close the application and replace only **MonolithHarness.exe** on Windows or **MonolithHarness** on Linux. Keep **database.sqlite** and existing resources. Extract GUI and CLI into separate writable folders.
