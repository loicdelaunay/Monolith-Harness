# Monolith Harness 1.60.0

This release improves conversation performance and adds a release version selector to the GUI updater.

## Conversations and agents

- Keeps Mermaid diagrams in a bounded cache, reuses unchanged renders, and virtualizes older chat messages to reduce work when scrolling long conversations.
- Adds settings to enable or disable Mermaid diagrams and mathematical notation in rendered Markdown.
- Adds optional Git worktrees for subagents that edit code. Successful work is integrated automatically when it can be merged cleanly.
- Adds Chat and Agent modes. Chat includes web research by default and optional Python script execution.

## Updates

- Choose **Latest** or pin the GUI to a specific compatible release in Settings → About. Checks and automatic installation respect the saved choice.

## Downloads

GUI and CLI packages are published separately for Windows x64 and Fedora Linux x64. macOS packages remain paused.
