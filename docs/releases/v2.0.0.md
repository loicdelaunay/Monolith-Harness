# Monolith Harness 2.0.0

## The 2.0 release line

GUI, CLI, Server and Flutter Android are now versioned together as 2.0.0. This release brings together the recent desktop navigation and appearance updates, customizable chat backgrounds, Vertex AI connectivity and Windows rendering/startup improvements, together with the latest tool-image corrections.

## Vertex AI tool images and screenshots

With Gemini 3 and newer models on the Vertex AI API-key adapter, images produced by a tool are attached to that tool’s native function response. Function responses are kept separate from ordinary text and image turns. This fixes the HTTP 400 “Requests ending with a model turn are not supported” error that could stop conversations after a screenshot and persist on subsequent messages.

Tool-image history reconstruction is shared by the engine, GUI context compaction and hosted generations. It preserves the tool’s attachments when rebuilding the model context. Gemini 1.x and 2.x retain their existing image transport.

## Desktop experience

The current desktop includes the compact title bar and workspace tools, separate searchable provider/model selection, the Fluent dark V2 palette, the compact sidebar footer, and six optional chat background effects with opacity and color controls. Recent rendering changes reduce repeated Markdown/layout work during streaming and CPU-intensive frame presentation on Windows.

## Downloads and updating

- GUI, CLI and Server: separate Windows x64 and Linux x64 portable downloads.
- Flutter Android: a signed ARM64 APK using the existing durable signing identity; the desktop-specific features above do not imply Android feature parity.
- Every release includes SHA-256 checksums; Windows GUI and CLI also retain the compatibility archive names recognized by older update clients.

Portable archives contain only the executable, license and startup instructions, with no user databases, API keys, logs or private workspaces. Back up your data and replace only the executable when updating. Keep existing databases and workspace folders. Android updates use the existing app package and signing identity.
