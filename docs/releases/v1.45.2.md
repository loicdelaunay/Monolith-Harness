# Monolith Harness 1.45.2

## Desktop improvements

- Much more compact **Model and thinking** panel: narrower layout, inline thinking choice and a small context editor. Use the information button for capacity details. Model autocomplete remains available.
- Context limits are saved **per model**, within each provider connection. Automatic mode uses the reported maximum when available; unknown capacities are clearly labelled as estimated fallbacks. Custom limits remain available and survive model changes and restarts.
- Tool bubbles appear immediately while executing, waiting for permission or queued, with arguments, activity and elapsed time. Completed results reuse the same bubble.
- Continuous selection across adjacent Markdown headings, paragraphs, lists and quotes makes copying a full section easier. Tables and code blocks retain their own selection surfaces.
- Reply footers group duration, response time and provider-reported reused tokens. Missing cache counters remain unknown; a reported zero is preserved.

- Fixes SQLite rollback for the recent model/context/cache migrations, so returning to an older schema can be followed by a normal upgrade.

## GUI and CLI shared engine

- New providers: **OpenRouter, Groq, Google Gemini, Mistral, Z.ai and NVIDIA NIM**, alongside existing compatible APIs and OpenCode. Configure your own account and key; pricing and quotas remain with each service.
- **Local · Beta** imports GGUF chat models and compatible complete Stable Diffusion checkpoints, with optional Hugging Face search/download and machine compatibility estimates. Models use the `model/` folder by default and are not included in these downloads.
- **Image generation · Beta** lets an enabled skill use a chosen image provider and model. Local image generation requires a compatible complete checkpoint and a downloaded runtime. Supported remote image APIs depend on the provider.
- Model loading reports **Preparation**, **Sending** and **Waiting for first tokens**. These are observed request stages, not a server progress percentage. Provider-reported cache reuse is persisted in replies and consumption records.
- Model capacity metadata is retained from compatible APIs, OpenCode and Gemini. Local GGUF imports read the declared context window without loading weights. Engine limits and available memory still apply. Refresh your models to discover capacities for existing connections.
- The CLI provider menu adds **Context per model**, with automatic and custom limits. Both interfaces share context accounting and compaction behavior.

## Downloads and updating

GUI and CLI downloads target **Windows x64** and **Fedora Linux x64**. macOS publication remains paused.

Each archive includes only its standalone launcher, license and startup instructions. No database, keys, logs, user profiles or downloaded models are included. Windows compatibility archives are identical aliases for older update clients; their launcher is also named `MonolithHarness.exe`.

Close the application, back up your folder and replace only the executable. Keep `database.sqlite` and existing resources. Install GUI and CLI into separate writable folders. Use **SHA256SUMS.txt** to verify each download.

Linux GUI requires X11/XWayland, GTK3 and WebKitGTK. Native desktop-control tools remain unavailable on Linux. Compilation and archive verification do not replace interactive checks on physical Linux hardware; the existing automatic repository checks run separately from packaging. Interactive UI checks were not run for this publication.
