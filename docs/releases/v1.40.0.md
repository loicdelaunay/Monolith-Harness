# Monolith Harness 1.40.0

GUI and CLI portable downloads for Windows x64 and Linux x64. macOS publication remains paused; historical macOS releases are retained.

## Desktop changes since 1.37.0

- **Tools → Preview:** open local PNG/JPEG/WebP/GIF/BMP/ICO, TXT and Markdown directly from chat links and compatible attachments. Switch between Raw and rendered Preview, fit/zoom images, copy raw content and refresh files. Reads, decoding and parsing run in the background with pagination, limits and cancellation on navigation. GIF displays a still frame; SVG, HTML, PDF and other formats retain the browser route.
- **Chat density:** Compact, Normal or Spacious in Appearance, including message padding, font size, line spacing and displayed history. Lists avoid duplicate blank lines; Shift+Enter inserts one newline.
- **General preferences:** choose automatic naming after the first user message or the first completed response, show/hide the Needs attention section and select a Windows rendering GPU preference (effective after restart).
- **Inactivity policies:** optional automatic archival and deletion, initially disabled, with default inactivity delays of 30 and 45 days. Active, pinned, favorite, displayed and pending conversations are preserved.
- **Tool activity:** execution durations remain visible in history; the active tool chip shows a short action description and elapsed time.

## Shared engine and CLI changes

- **Preloading context:** GUI and CLI identify preparation and waiting before meaningful text, reasoning or tool fragments arrive. Estimated context size and elapsed time are shown; GUI tooltips include observed request stages, message count and encoded payload size when available.
- Empty stream heartbeats retain the preloading state. Automatic retries restart the wait counter. No provider prefill percentage or cache hit is inferred.
- Automatic naming timing is shared between GUI and CLI.

## Downloads and update

Extract the appropriate GUI or CLI archive into a writable folder. Windows launchers are named `MonolithHarness.exe`; Linux launchers are named `MonolithHarness`. Close the application before replacing its executable and preserve your portable data. Archives contain only the executable, MIT license and startup instructions, with SHA-256 checksums. Windows compatibility aliases are included for older update clients.

No separate .NET or Python installation is required. Linux GUI needs X11 or XWayland, GTK3 and WebKitGTK for the embedded browser. Optional integrations retain their own prerequisites. Linux and desktop interaction are not verified on physical Linux hardware for this version.

Compilation and release packaging are performed for both platforms. Interactive UI checks and automated tests were not run for this update.
