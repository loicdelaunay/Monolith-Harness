# Monolith Harness 1.75.1

GUI and CLI share version 1.75.1. This release includes the changes since 1.73.1.

## Highlights

- Proposed changes open in a separate native review window, with files on the left and change blocks on the right. Added lines are green and previous/removed lines are red. Accept or reject individual blocks, whole files or the entire proposal. Finish becomes available once every block has a decision; closing preserves pending choices. A prominent chat card shows changed-file counts and added/removed line totals. Code rows remain contiguous without artificial blank spacing.
- The composer adapts progressively to available width: token speed hides first, then the context percentage while retaining its ring, followed by compact controls and proportional reduction when necessary. Export, Tools and Auto switch to icons when the header is narrow. Details return when the window widens, preserving saved preferences and tooltips.
- Repeated sidebar reordering restores drag properties on recycled chat rows and defers list rebuilding until the native drop has returned. A thin insertion marker identifies the position above or below the target; same-project reorders preserve the active chat and draft.
- Attachment previews shrink with the available width and window height, remain square under text zoom, and keep images, titles and removal controls within their frames. Collapsed attachments show “Voir pièces jointes (X)” beside the expand arrow, with an updated count. Many attachments retain a compact horizontally scrolling row.

See [CHANGELOG.md](https://github.com/loicdelaunay/Monolith-Harness/blob/v1.75.1/CHANGELOG.md) for details.

## Downloads

Choose the GUI or CLI archive for Windows x64 or Fedora Linux x64. Historical Windows archive-name aliases contain the same executable. `SHA256SUMS.txt` lists the fingerprints of all downloads.

Archives contain only the executable, license and startup instructions. They contain no database, credentials, logs or user workspace.

## Updating

Close the application, back up your workspace, and replace only the executable. Keep `database.sqlite`, `workspace/` and your existing resources. Optional Git, Docker/Podman, OpenCode and MCP integrations keep their own prerequisites.

## Validation

GUI and CLI compile and are published locally on Windows x64 at 1.75.1. The isolated native responsive scenario passed 1,507 checks across two text-zoom levels, 70 width changes, short windows, attachment folding/counting, many attachments and six successive chat reorders. Another 13 presentation regression checks passed, including image fullscreen preview and attachment removal without deleting its source file. The reorder checks exercise persistence, refreshing and native row state; a complete operating-system mouse drag gesture is not automated.

GitHub rebuilds both interfaces for Windows x64 and Fedora Linux x64, checks clean archive contents and uploaded file fingerprints, and prepares both releases as drafts before publication.
