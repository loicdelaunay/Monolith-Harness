## Flutter Android

- The Flutter Material application replaces the removed Uno Android project in current sources.
- Projects and discussions in a reorderable sidebar, streamed Markdown answers, tools grouped into chat bubbles, long-press message actions and live reasoning status.
- Providers, skills, file attachments, scoped memory, permissions and isolated full-screen HTML apps with local Tailwind CSS and Chart.js.
- ARM64 APK for Android 8+. Public APK signed with the durable release certificate. Flutter uses application ID `com.monolithharness.flutter`; previous Uno data is not migrated. Development builds signed with a different certificate cannot be updated in place by this APK.

## Downloads

Windows and Linux archives contain only the launcher, LICENSE and startup instructions. Existing workspace data remains outside the downloads. Compatibility filenames for older Desktop and CLI updaters are included. SHA256SUMS files accompany every distribution.

Material file icons: https://github.com/material-extensions/vscode-material-icon-theme (MIT; license embedded with the icon assets).
