# Monolith Harness 1.94.0

This release includes the Desktop and shared-engine improvements from 1.92.0 and the Server collaboration updates from 1.93.0 and 1.94.0.

## Desktop and shared engine

- User messages display HTML as source. Reasoning cards have bounded height with their own scroll area.
- New conversation exports record observed completion reasons, provider finish reasons, stream completion, cancellation, errors and retry attempts. Chat settings offer optional continuation for empty or output-limited responses; it is disabled by default.
- Long message drafts use debounced skill suggestions and a cached skill catalog.
- File citations have rounded, theme-aware outlines and hover feedback. Attachments have contextual actions, including opening folders in the file explorer.
- Pending file proposals stay above the message composer. Appearance settings can show aggregate token speed for concurrent conversations, including subagents.

## Server, Desktop and CLI collaboration

- Desktop adds a Local / Cloud sidebar, shared and public conversations, joining with a share code and connection status details.
- Desktop and CLI synchronize shared providers, cloud projects and conversations automatically, with configurable full synchronization intervals.
- Shared conversations display reasoning, tool calls, ongoing responses, comments and viewer counts in their own viewer.
- Cloud messages identify their author with an avatar and account name. Conversation names and messages synchronize between members and devices.
- Shared provider requests respect the server queue and can be cancelled. Provider settings can test connections and detect published models; cloud projects can invite existing accounts.
- The Server remains optional. See the [Server guide](https://github.com/loicdelaunay/Monolith-Harness/blob/v1.94.0/docs/server.md) for deployment and isolation requirements.

## Flutter Android

- ARM64 APK for Android 8+, aligned to version 1.94.0 (build 131) and signed with the existing durable certificate.
- Android keeps its current Flutter features. Server connection is not available in this version.

## Downloads

Desktop, CLI and Server include Windows x64 and Fedora Linux x64 downloads. Archives contain only the launcher, LICENSE and startup instructions. No databases, credentials, logs or workspaces are distributed. Desktop and CLI retain compatibility filenames for existing updaters. Each release includes SHA256SUMS.txt.

The root README uses the existing rounded Desktop, CLI, Android and Server logos and links to all four releases.
