# Monolith Harness 1.66.0

This release adds local command validation to Automatic permissions, with matching portable GUI and CLI packages.

## Command approvals

- A compact shield beside the composer settings shows the global approval mode and opens Ask, Automatic, Deny all or Settings / Permissions. Ask remains the default.
- Selecting Automatic for the first time explains installation, downloads the pinned LANCET Nano model and CPU components, verifies the model files and prepares the local runtime. The mode activates only after successful setup.
- Each compatible terminal command is analyzed locally before execution. Risky, uncertain or oversized commands, unsupported shells and unavailable analysis require one-time human approval. Saved directory grants cannot bypass this check. Explicit project Ask and Deny rules remain effective.
- More info uses the conversation model to explain a command's impact without execution tools. The dialog states that this request may send the command to that provider. The explanation renders Markdown headings, lists, emphasis and code blocks; the original command has its own copyable block, with working directory and shell/timeout information separated.
- The CLI shares the same command validation and offers first-use installation.

LANCET analyzes inert command text and can make mistakes; it is not a security sandbox and does not inspect files or scripts. Bash, PowerShell and cmd are supported. Unknown shells, including zsh/dash, Python scripts and external engines without exact command metadata require human review. Other permission types keep their existing Automatic behavior.

## Composer

- Centers the model name, thinking badge and context/token-speed indicators vertically beside Stop and Send.
- Preserves compact layout and existing responsive behavior.

## Downloads

GUI and CLI packages are published separately for Windows x64 and Fedora Linux x64. Archives contain only the application, license and startup instructions. The optional LANCET model is downloaded after installation is accepted; it is not included in the archive. Existing portable data stays in place when updating.

Each release includes **SHA256SUMS.txt**; Windows packages also include compatibility download names for older update clients.
