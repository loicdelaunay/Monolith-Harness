# Monolith Harness 1.55.0

## What changed

- Stable **More information** heading: no switching between the model name and the previous label, with context/speed still visible in the collapsed header.
- Tool tabs move to the top of the panel. A compact toolbar groups each tool's information and actions; Assets keeps guides, grid and frame options in a menu.
- **Desktop / Mobile** Web display and **browser_viewport** for the AI. Mobile previews a 390 px responsive layout and preserves the page; desktop restores the full pane width. This does not emulate a phone OS or user agent.
- **Complete design** is applied proactively to complex work, with useful discovery questions, agreed design/technology choices, verification and complete delivery.
- Includes the preceding local Chat fixes: reasoning locked off while preserving Agent preferences, a compact aligned mode/settings capsule, and clear handling of models that require reasoning.

## Downloads

Both GUI and CLI are available for Windows x64 and Fedora Linux x64. macOS publication remains suspended.

Archives contain the launcher, license and startup instructions. User databases, keys, logs and profiles are excluded. Each release includes SHA256SUMS.txt and compatibility filenames for older updaters.
