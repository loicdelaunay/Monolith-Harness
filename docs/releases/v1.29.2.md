# Monolith Harness GUI 1.29.2

- Nouveau logo M, icônes de l’application et captures du README actualisées.
- Le lanceur publié s’appelle `MonolithHarness.exe` sur Windows et `MonolithHarness` sur macOS et Linux.
- L’updater Windows utilise ce nouveau nom. Les noms des archives et les données portables restent compatibles.

## Plateformes

Windows x64, macOS Apple Silicon, macOS Intel et Linux x64 (Fedora). Chaque archive contient uniquement le lanceur GUI, la licence et les instructions. Vérifier les téléchargements avec `SHA256SUMS.txt`.

## Installation et transition

Fermer l’application et sauvegarder son dossier. Pour passer d’une version antérieure, remplacer manuellement l’ancien lanceur par `MonolithHarness.exe` (ou `MonolithHarness` sur macOS/Linux) dans le même dossier. Conserver `database.sqlite`, les ressources et les paramètres. La mise à jour automatique est ensuite disponible sur Windows. La capture du README montre la même interface depuis le build source 1.29.1.

Sur macOS, extraire avec `tar -xzf` pour conserver les permissions. Les builds ne sont ni signés ni notariés ; les interactions natives nécessitent une validation manuelle sur un Mac. La GUI Linux utilise X11/XWayland, GTK3 et WebKitGTK pour son navigateur.
