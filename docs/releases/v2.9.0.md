# Monolith Harness 2.9.0

## Thinking modes per model

- The Models tab of each connection has a Thinking section with three modes per model:
  - **Automatic discovery** shows the detected levels and where they come from: capabilities declared by the API when models are imported, built-in catalogues and the model identifier.
  - **Manual** lets you select the levels the model accepts. The discovered levels are kept and restored when you switch back to automatic.
  - **Default** sends no thinking parameter at all and only offers Auto.
- Chat, quick model levels and the CLI follow this choice. A level rejected by the API is still removed for the session.
- Better automatic discovery: request parameters declared by gateways such as OpenRouter, OpenAI, Gemini and DeepSeek model families recognized behind gateways and proxies, and newer Gemini Pro generations.

## Chat

- The "Thinking · requested / sent" details and transport parameters are no longer shown in conversations, including messages saved by 2.7.0 and 2.8.0. Genuine compatibility notices, such as a DeepSeek fallback, remain visible.

## Providers

- The API base URL is on the Connection tab.
- Connections provided by a Monolith server are labelled and read-only in the editor. Deleting or editing them there previously appeared to work, but saving ignored it and the connection came back. Remove them on the server or sign out in Settings > Server.

## Downloads

GUI, CLI and Server are available for Windows x64 and Linux x64. Flutter Android is a signed ARM64 APK. SHA256SUMS.txt is included in every release.

## Validation and limits

- The full regression suite (809 checks), the CLI suite (202 checks) and the Electron host tests (7/7) passed.
- The full desktop UI smoke test passed, including the manual thinking levels, and a new provider deletion smoke test covers deleting connections in use and server-provided connections.
- Thinking modes are configured in the desktop GUI and also apply to the CLI, which shares its profile. The Android app keeps its own settings and is unchanged apart from the version number.
