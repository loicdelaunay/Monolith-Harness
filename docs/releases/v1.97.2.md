# Monolith Harness 1.97.2

## Automatic retry for incomplete JSON errors

The automatic retry setting now covers HTTP 400 responses reporting an incomplete JSON request received by the provider or its gateway, including `json_invalid` / `JSON decode error` with `Unterminated string` or an unexpected end of data. The configured retry count and delay apply. Persistent failures still stop after the configured attempts; the underlying gateway truncation may require a server-side fix.

Other HTTP 400 errors (invalid parameters, context limits, model configuration) and authentication errors remain excluded. Retrying a model request does not replay previously executed tools and does not disable reasoning or tools through compatibility fallback.

## CLI compatibility

Graphical desktop tools remain unavailable in the CLI. Host capability checks now retain the established explicit unsupported-tool response before accessing UI Automation settings.

## Included desktop and server improvements

- Windows keyboard and mouse skills: configurable UI Automation / API and Legacy modes, AI mode choice and optional fallback, with permissions and bounded native calls. See [the input guide](https://github.com/loicdelaunay/Monolith-Harness/blob/main/docs/desktop-input.md).
- File citation verification, native Mermaid fallback, reasoning display levels and scrolling, expanded long-message editor, project source-folder display and settings-save improvements.
- Server announcements, queue positions, one-click server mode and opt-in usage statistics.
- Server startup update options, maintenance administration and operating-system service installation.

See [the changelog](https://github.com/loicdelaunay/Monolith-Harness/blob/main/CHANGELOG.md) for the complete 1.95.0–1.97.2 changes.

## Downloads

Separate GUI, CLI and Server releases provide Windows x64 and Fedora Linux x64 archives. Flutter Android provides a durable signed ARM64 APK. All downloads include SHA-256 checksums and no user databases, API keys or private workspaces. Existing profiles and data must be kept when replacing the executables.

Flutter Android's app version is aligned with this release; its mobile feature scope remains unchanged. Desktop UI Automation is Windows-only; macOS retains Legacy input and Linux desktop input remains unavailable. The CLI retains its existing graphical-tool exclusions.
