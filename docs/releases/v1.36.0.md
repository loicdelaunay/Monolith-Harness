# Monolith Harness GUI 1.36.0

## Nouveautés depuis 1.33.1

- **Réglages → Compactage** : activation automatique, seuil de déclenchement, cible de contexte, force Douce / Équilibrée / Forte / Personnalisée, budget du résumé, instructions personnalisées et stratégies par échanges récents, historique complet ou résultats d’outils. Le compactage manuel reste disponible.
- La GUI, le CLI et les sous-agents compatibles partagent la même politique. Les résumés couvrent les segments sélectionnés ; la réduction est contrôlée avant l’archivage. Les messages originaux restent dans la base en cas d’échec.
- Les projets, namespaces, assemblies, ressources et scripts utilisent désormais **MonolithHarness**. Le nom des lanceurs reste `MonolithHarness.exe` sur Windows et `MonolithHarness` sur Linux.
- Bases, profils, clés enregistrées et anciens fichiers `index.ohm` restent compatibles. Les anciennes conventions d’archives Windows restent reconnues par la mise à jour automatique.
- Même moteur que le CLI 1.36.0, qui ajoute une icône terminal distincte, une animation de réflexion, l’historique avec ↑/↓ et l’activité de chaque sous-agent.

## Téléchargements et installation

- **Windows x64** : `MonolithHarness-v1.36.0-win-x64.zip`.
- **Linux x64** : `MonolithHarness-v1.36.0-linux-x64.tar.gz`, construit dans Fedora 44.
- La publication **macOS est temporairement suspendue**. Les anciens téléchargements restent disponibles sur leurs releases.

Chaque archive contient uniquement le lanceur autonome, la licence et les instructions. Vérifier son empreinte avec **SHA256SUMS.txt**. Les archives Windows de compatibilité ont le même contenu que l’archive au nouveau nom.

Fermer l’application, sauvegarder son dossier puis remplacer uniquement l’exécutable. Conserver `database.sqlite`, les ressources et les paramètres. Installer GUI et CLI dans des dossiers séparés. Les installations antérieures à 1.29.2 doivent remplacer manuellement leur ancien lanceur.

Sur Linux, extraire avec `tar -xzf` pour conserver les permissions. La GUI utilise X11/XWayland et nécessite GTK3/WebKitGTK pour son navigateur. Les outils natifs de contrôle du bureau ne sont pas disponibles sur Linux.
