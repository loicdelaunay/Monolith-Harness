# Monolith Harness 1.46.0

## Automatic GUI updates

**Settings → About** now offers three persistent update levels:

| Level | Behavior |
| --- | --- |
| **Disabled** | No automatic update checks. Manual checking remains available. |
| **Notify only** | Check at startup and every two hours while the app is open; show an available update without installing it. This is the default. |
| **Install automatically** | Perform the same checks and install the verified release when the workspace is idle. |

Existing update preferences are retained. An **Update** button appears **above Scheduled tasks** when a newer compatible GUI release is found. It stays available until the update is installed or a successful check finds no newer release.

Manual and automatic installation share the SHA-256-verified download and restart flow. Automatic installation waits for running agents, queued messages, conversation drafts, editing windows and scheduler activity, then checks again before restarting. Disabling the mode cancels its pending background check/download. Download failures back off for two hours.

Automatic installation requires a **published standalone Windows executable**. Linux checks can report a release, but replacing the executable remains manual. The CLI retains its existing update controls.

## Downloads and updating

Both **GUI and CLI 1.46.0** have **Windows x64** and **Linux x64** archives. macOS publication remains paused.

Each archive contains only its standalone launcher, **LICENSE** and **README.txt**. No database, keys, logs, profiles or downloaded models are included. Windows legacy-name archives are byte-identical compatibility aliases for older update clients. Each release includes **SHA256SUMS.txt**.

Extract into separate writable folders for GUI and CLI. To update manually, close the application, back up the workspace and replace only **MonolithHarness.exe** on Windows or **MonolithHarness** on Linux. Keep **database.sqlite** and existing resources.

Linux GUI requires X11/XWayland; its browser also needs GTK3 and WebKitGTK. Native desktop-control tools remain unavailable on Linux.
