# MonolithHarness GUI 1.29.0

Choose `OhMyHarness-v1.29.0-win-x64.zip`, `OhMyHarness-v1.29.0-osx-arm64.tar.gz` (Apple Silicon), `OhMyHarness-v1.29.0-osx-x64.tar.gz` (Intel), or `OhMyHarness-v1.29.0-linux-x64.tar.gz`. Extract into a writable folder and launch `MonolithHarness.App` (`.exe` on Windows). Check your archive against the attached `SHA256SUMS.txt`.

## Agents and swarm coordination

Auto now evaluates delegation before starting each request. Settings → Agents offers **Selective, Balanced, Proactive (default) and Swarm**, explanations of their behavior and additional coordination instructions. Teams can use successive waves and delegate independent work to descendants. Workers inherit enabled tools and permissions, including terminal, browser, desktop, MCP and permitted Git writes. Long work compacts its context for continuation.

The previous six-agent/eight-step caps are replaced by configurable safeguards: **64 agents per request, 8 parallel model requests, 3 delegation levels and 200 steps per worker** by default. Team sizes and presets can exceed six members. Cancellation, Plan mode, sandbox restrictions and repeated-call protection remain active. OpenCode workers use their authorized native tools; native nested delegation remains disabled for application-managed workers because those descendants cannot be included in the shared budget.

## Also included from 1.28.0

- Separate optional logos for light and dark themes, and theme brightness icons.
- Multiple default project folders and conversation resource preservation fixes.
- Optional operating-system notifications.
- German and Spanish interface languages, with flags in the language list.
- Thinking activity, a counter after 30 seconds without model content and a short provider-supplied reasoning excerpt.
- Slash autocomplete and quick settings with `/agents`, `/plan`, `/goal`, `/model`, `/thinking`, `/theme`, `/retry`, `/settings`, `/stop` and `/help`.
- Separate Git read/write permissions, database optimization and a confirmed data reset.
- Ctrl+F to search the full conversation history.

Each archive contains only the executable, MIT license and startup instructions. It includes no database, profiles, credentials, logs or user data. macOS builds are unsigned and not notarized. The Linux GUI uses X11 or XWayland and needs GTK3 and WebKitGTK for its embedded browser. Close the app and replace only its executable when updating; preserve your existing portable data.
