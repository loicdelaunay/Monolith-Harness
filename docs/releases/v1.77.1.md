# Monolith Harness 1.77.1

GUI and CLI share version 1.77.1. This release fixes a native Markdown rendering failure introduced during streamed responses.

## Fixes

- Bounds Markdown source slices to the text actually received, including incomplete streamed blocks, incremental paragraph reuse and native file previews. Prevents the `Index and length must refer to a location within the string` exception from these slices.
- If native Markdown rendering still fails, shows the full response as selectable plain text and allows generation to continue. Formatted rendering is retried on the next update, and a diagnostic warning is recorded without storing response content.

See [CHANGELOG.md](https://github.com/loicdelaunay/Monolith-Harness/blob/v1.77.1/CHANGELOG.md) for details.

## Downloads

Choose the GUI or CLI archive for Windows x64 or Fedora Linux x64. Historical Windows archive-name aliases contain the same executable. `SHA256SUMS.txt` lists the fingerprints of all downloads.

Archives contain only the executable, license and startup instructions. They contain no database, credentials, logs or user workspace.

## Updating

Close the application and replace only the executable. Keep `database.sqlite`, `workspace/` and your existing resources.

## Build and publication

GUI and CLI compile and are published locally on Windows x64 at 1.77.1. No new automated functional tests were added or run for this fix. GitHub rebuilds both interfaces for Windows x64 and Fedora Linux x64, checks archive contents and uploaded file fingerprints, and prepares both releases as drafts before publication.
