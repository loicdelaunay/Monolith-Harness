# Monolith Harness 1.98.0

## Configurable loop detection

Desktop Settings now includes a Loop detection section. Enable or disable repeated-call detection, choose the number of consecutive identical tool calls (default: 3, range: 2–50), and ask whether to stop or continue once, or stop automatically. The captured settings also apply to subagents and the shared CLI/Server engine. Short terminal waits are excluded; model request retries and agent step limits remain independent.

## Desktop diagnostics and navigation

Tools now shares the Settings row in the sidebar. Tools > Debug > Diagnostics opens a native window with process CPU/RAM, managed memory, uptime, running conversation/tool counts, runtime and operating-system details, filterable logs, and recorded generation errors and interruptions. Process metrics refresh every two seconds; stored errors refresh every ten seconds. CPU/RAM measurements cover Monolith itself, excluding external models and terminal processes.

## Native LaTeX rendering

Inline formulas, display equations and fenced latex/tex/math blocks render offline using a native math engine, including when chat WebView previews are disabled. Common LaTeX delimiters are recognized and the rendering follows the application's colors. Incomplete, oversized or unsupported formulas keep a readable source fallback. This is a mathematical formula renderer, not a full TeX document compiler.

## Tool authorization details

New tool bubbles show a colored shield beside Details when an authorization decision is recorded. Its floating window explains manual approval, saved grants, project rules, global permission modes and command-validator results when available. These records persist in local history and exports, and are excluded from model requests. Old messages do not gain reconstructed approval evidence.

## Downloads

GUI, CLI and Server provide separate Windows x64 and Fedora Linux x64 archives; Flutter Android provides a durable signed ARM64 APK. Versions are aligned at 1.98.0. The Android package contains the existing Flutter application rebuilt at the new version; the new settings and diagnostics interface is desktop-specific.

All downloads include SHA-256 checksums. Archives contain no user databases, keys, logs or private workspaces. Preserve your existing data when replacing the executables. See [the changelog](https://github.com/loicdelaunay/Monolith-Harness/blob/main/CHANGELOG.md) for details.
