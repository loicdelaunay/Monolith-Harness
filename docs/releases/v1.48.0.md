# Monolith Harness 1.48.0

Conversations without a project folder now have their own file workspace at **workspace/conversations/chat-\<id\>/** beside the launcher. The GUI displays **Workspace / Espace de travail**, and both interfaces use that directory for source tools and new terminals. Files remain available after restarting or switching conversations. Attaching a real folder uses that folder; removing it restores the conversation workspace. Plan mode and tool permissions still apply.

Application-managed folders are grouped under **workspace/**: skills, local models, browser profiles, scripts, Python runtimes, drawings, images, sandboxes, logs and exports. Startup migrates existing folders and stored paths. External project folders and **database.sqlite** stay in place. Existing destination folders keep their contents, with conflicting legacy folders preserved in **workspace/legacy-imports/**. Conversation files are retained when a chat is deleted.

Both **GUI and CLI 1.48.0** are available for **Windows x64** and **Linux x64**. Each archive contains the standalone launcher, **LICENSE** and **README.txt**. Both releases include **SHA256SUMS.txt** and Windows compatibility aliases.

To update manually, close all application instances and replace only **MonolithHarness.exe** on Windows or **MonolithHarness** on Linux. Keep **database.sqlite**, **workspace/** and existing resources. Extract GUI and CLI into separate writable folders. Back up the complete portable folder before reverting to a release older than 1.48.0.
