# MonolithHarness GUI 1.27.0

Choose `OhMyHarness-v1.27.0-win-x64.zip`, `OhMyHarness-v1.27.0-osx-arm64.tar.gz` (Apple Silicon), `OhMyHarness-v1.27.0-osx-x64.tar.gz` (Intel), or `OhMyHarness-v1.27.0-linux-x64.tar.gz` (Fedora 44). Extract into a writable folder and launch `MonolithHarness.App` (`.exe` on Windows). Check the selected archive against the attached `SHA256SUMS.txt`.

The new optional **GIT** skill gives the agent repository status, diffs, history, branches, explicit file staging, commits and configured remote synchronization under the existing permission controls. **FILE INDEX** creates a portable, searchable `index.ohm` with file and folder descriptions. It keeps existing indexes current after source edits and reconciles external changes on the next read. The agent can enrich structural summaries after inspecting files; changed model explanations are marked for review.

This download also includes the 1.26.1 fix: the memory database viewer opens in its own window and the sidebar version chip displays the full version. See the [full changelog](../../CHANGELOG.md) and [GIT and FILE INDEX guide](../git-file-index.md).

The archive contains only the executable, MIT license and startup instructions. It has no database, profiles, credentials, logs or user data. macOS builds are unsigned and not notarized; native interaction needs validation on a real Mac. The Linux GUI uses X11 or XWayland and needs GTK3 and WebKitGTK for its embedded browser. On Mac or Linux, close the app and replace only the executable when updating.
