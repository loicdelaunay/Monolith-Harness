# Monolith Harness 1.88.0

GUI and CLI share version 1.88.0. Android is distributed as a separate signed preview. This publication includes the changes since 1.84.0.

## Changes

- GUI and Android replies display Markdown images and HTML/CSS cards with access to their source. Complete raw HTML documents are grouped into a single preview instead of scattered fragments; saved messages benefit without altering their content.
- Tailwind CSS 4.3.3 and Chart.js 4.5.1 are bundled locally, with independent switches and no CDN requests. Desktop keeps a native fallback; interactive previews execute inside a sandbox with no network, file access or native bridge.
- Android adds the Create web app skill (/create-web-app) and fullscreen HTML/CSS/JavaScript previews.
- Desktop settings now have a Chat tab and a searchable index across sections. WebView permissions for tools and chat are independent; inline interactive HTML is optional.
- Desktop Tailwind follows the application's theme and palette by default, with a separate toggle. An optional dynamic height follows the HTML content with a maximum of 2000 logical pixels and internal scrolling for longer pages.
- HTML preview windows reuse their instance, stabilize startup/painting and recover the inline preview on return or close. Native fallback and source remain available if WebView is unavailable.
- Automatic retries, conversation naming, Attention required and conversation maintenance remain in General. Test is located below Notifications.

## Downloads and updates

Choose GUI or CLI for Windows x64 or Fedora Linux x64. Archives contain exactly the executable, license and startup instructions, with no database, API keys, logs or workspace. Historical Windows-name aliases contain identical downloads. SHA256SUMS.txt lists all fingerprints.

Close desktop applications and replace only their executable. Keep database.sqlite, workspace/ and existing resources. Android uses its existing durable signing identity and keeps its private data when updated from a release signed with the same certificate.

## Validation scope

Windows GUI and CLI were compiled and published locally with matching versions. GitHub Actions rebuilds Windows and Fedora, validates the allowlisted archive contents and remote SHA-256 digests, and prepares both desktop releases as drafts before making them public. Android packaging is separate and uses its durable release certificate.

The HTML grouping and fullscreen web app were checked on a Pixel 7 Pro with source build 1.86.1. The latest desktop preview lifecycle/flicker changes still require visual confirmation on the user's PC. No new manual automated functional suite was requested for these changes; existing compatibility workflow results are separate from release packaging. macOS runtime and all Android provider/tool combinations are not validated by this release.
