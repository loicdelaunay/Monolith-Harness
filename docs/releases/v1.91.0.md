# Monolith Harness 1.91.0

## Optional Server

- First standalone Windows x64 and Linux x64 Server downloads, with a Blazor/MudBlazor web interface, REST/OpenAPI, WebSocket events and the shared engine.
- Accounts, configurable roles, shared providers, live sharing of local conversations, cloud projects, scheduled requests and a configurable queue.
- Server use is optional. See the [English Server guide](https://github.com/loicdelaunay/Monolith-Harness/blob/v1.91.0/docs/server.md) for setup, approvals, isolation requirements and current limits.

## Desktop and CLI

- Desktop Settings → Server and CLI `/server` connect to a server without changing standalone local use.
- Shared provider keys stay on the server. Cloud runs send approval requests and questions back to their initiating user.
- Desktop can share a local conversation live; invited viewers can read and comment while tools continue running locally.

## Flutter Android

- ARM64 APK for Android 8+, aligned to version 1.91.0 and signed with the existing durable certificate.
- Android remains local; server connection is not available in this version.

## Downloads and updates

Desktop, CLI and Server archives contain only the launcher, LICENSE and startup instructions. Existing databases, configurations, keys and workspaces are not distributed. Desktop and CLI retain compatibility filenames for existing updaters. Every release includes SHA256SUMS.

Cloud code execution requires a configured container runtime by default. Container execution has not been validated end to end on the development machine; resource limits are monitored by the server. See the Server guide before enabling remote execution.
