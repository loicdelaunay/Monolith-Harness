# OhMyHarness GUI 1.26.0

Choose the archive for your system: `win-x64.zip`, `osx-arm64.tar.gz` (Apple Silicon), `osx-x64.tar.gz` (Intel), or `linux-x64.tar.gz` (Fedora 44). Extract into a writable folder and launch `OhMyHarness.App` (`.exe` on Windows). Check the archive against `SHA256SUMS.txt`.

This release includes the changes since 1.21.2: compact project conversations, configurable retries and notifications, agent role presets, font choices, a memory database viewer, independent project folder expansion, pinned chats with project activity badges, and an offline changelog dialog. Appearance now offers custom themes with 21 colors and a live preview. GitHub updates and logs moved to About.

The download contains only the executable, license and startup instructions. It contains no database, profile, keys or user data. The chat model is configured separately. macOS builds are unsigned and not notarized. Linux GUI uses X11 or XWayland and requires system GTK3 and WebKitGTK for the embedded browser. Automatic executable replacement is available on Windows; on Mac or Linux, close the application and replace only the executable.

See the [full changelog](../../CHANGELOG.md), [macOS guide](../macos.md) and [Fedora guide](../fedora.md).
