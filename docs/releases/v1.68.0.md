# Monolith Harness 1.68.0

This release improves conversation display, composer controls and command approval feedback.

## Chat display and search

- Settings / General adds **Virtualize chat display**, enabled by default. Disable it to retain all rich bubbles in the displayed conversation, using more memory.
- **Ctrl+F** highlights matching text inside messages, including newly realized bubbles and streamed answers. Clearing or closing search removes the highlights.
- The composer can collapse attachment and resource previews without removing their content. The choice is retained per conversation during the session.

## Live generation feedback

- The compact composer token speed uses received output from the **last two seconds**, with a separate measure per conversation and model call. Text-based estimates are marked accordingly. Existing speed tooltip statistics remain unchanged.
- The activity glow stays continuous during streamed updates, and circular indicators rotate smoothly.
- Automatic command checks show a shield, **Checking…** and an animated ring beside the activity chip. The tooltip identifies the current validation stage. Providers do not supply a completion percentage.

## Command approval dialog

The exact copyable command is displayed first, followed by a categorical risk bar: **green** for a valid low-risk decision, **orange** for review or unavailable analysis, and **red** for a risky classification. Working directory, shell, timeout and impact analysis appear below. The previous warning banner is removed. Human approval actions and permission rules are unchanged.

## Downloads

Separate GUI and CLI packages are provided for Windows x64 and Fedora Linux x64. Archives contain only the application, license and startup instructions; they do not contain user data. Preserve existing portable data when replacing the executable.

Each release includes **SHA256SUMS.txt** and Windows compatibility archive names for older update clients.

## Validation

Both Windows interfaces were compiled locally at version 1.68.0. Interactive visual behavior has not been checked in this release preparation.
