# Monolith Harness 1.104.3

## Faster Windows desktop interface

This release includes the desktop performance improvements from 1.104.1 through 1.104.3: incremental Markdown and reasoning updates during streaming, fewer synchronous layout passes, throttled activity updates and cached settings in frequently used paths. Chat background motion pauses while replies stream and while scrolling, then resumes in place.

Windows builds include precompiled interface code for faster startup. Frame presentation uses a timer aligned with the primary display refresh rate (60–240 Hz), avoiding CPU-intensive driver waits for vertical synchronization. Diagnostics reports whether the interface uses GPU or software rendering. Performance depends on the machine, display and graphics driver.

## Appearance and navigation

Fluent dark V2 combines near-black surfaces with #1D6FC8 accents and primary actions. The compact sidebar footer groups global token speed, server status with a native mode switch, and Settings beside the Tools dropdown.

Chat backgrounds offer Floating code, Aurora, Constellation, Ripples, Particles and Luminous grid. Choose an opacity from 0 to 100% and either the theme color or a custom color, with immediate preview and saved preferences. Effects are disabled by default, use bounded native scenes, and respect reduced-motion settings.

Desktop navigation includes a compact custom title bar, workspace tool shortcuts and refreshed browser/tool chrome. Provider and model selection are separate and searchable.

## Vertex AI / Google Cloud

Desktop, CLI and Server support ADC authentication, project API keys and Vertex AI Express keys. Desktop connection checks report their result directly below the button and use the selected model's token-counting endpoint. Connection success does not guarantee generation access or billing-credit eligibility. See the [Vertex AI guide](https://github.com/loicdelaunay/Monolith-Harness/blob/main/docs/vertex-ai.md).

## Downloads and updates

GUI, CLI and Server have separate Windows x64 and Linux x64 archives. Flutter Android provides a durable signed ARM64 APK. All four packages use version 1.104.3; Android is the existing Flutter application rebuilt at this version, and the desktop changes above do not imply Android feature parity.

All downloads include SHA-256 checksums. Portable archives contain only the executable, license and startup instructions, with no user databases, keys, logs or private workspaces. Preserve your existing data when replacing an executable. The Android APK retains its established signing identity for updates.
