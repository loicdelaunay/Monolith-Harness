# Monolith Harness 1.54.0

## Chat and Agent

A persisted Chat / Agent switch is available in the composer, with Agent enabled by default. Chat offers Web research enabled by default and optional Python script execution, without project, terminal, MCP or subagent access. Both skills are configurable per conversation using the settings button to the right of the mode switch. The CLI exposes /chat, /agent and /chat-skills.

## A clearer composer

The Model, speed and context section shares the sidebar background. When collapsed, its header keeps a live context-usage ring, percentage and generation throughput on one line. Preview opens directly from compatible chat files, with redundant empty-state text and the Tools menu entry removed.

## Useful provider errors

GUI and CLI now retain the upstream error message and useful provider/quota details when supplied by the API, including suggested Retry-After delays and rate-limit counters. Sensitive credentials are redacted and displayed details are bounded. Retry count and timing retain their configured behavior; a provider may still omit the cause of a rate limit.

## Downloads and updating

Both **GUI and CLI 1.54.0** are available for **Windows x64** and **Linux x64**. Archives contain only the launcher, LICENSE and README.txt. Each release includes SHA256SUMS.txt and Windows compatibility aliases. macOS publication remains paused.

Close the application before replacing its launcher. Keep database.sqlite, workspace/ and existing resources. Extract GUI and CLI into separate writable folders.
